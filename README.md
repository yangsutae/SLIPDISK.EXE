# SLIPDISK.EXE 픽셀 프로토타입

플로피 디스크 속 컴퓨터가 파일을 먹고, 백신을 먹은 뒤 바이러스까지 먹는 선입력 퍼즐이다. 방향을 미리 입력한 뒤 ENTER를 누르면 컴퓨터가 벽에 닿을 때까지 미끄러진다. 게임 화면은 픽셀로 그리고, 부팅·타이틀·스테이지 선택·결과·일시정지·설정·전체 클리어 화면이 이어진다. 1~4단계 12개 레벨이 들어 있다.

- 바로 플레이: https://yangsutae.github.io/SLIPDISK.EXE/
- 로컬 실행: `index.html`을 브라우저에서 연다. 같은 폴더의 `css/`, `data/`, `js/`가 함께 있어야 한다. 설치, 빌드, 서버, 인터넷 연결은 필요 없다.
- 휴대폰에서도 플레이할 수 있다.

## 조작

메뉴에서는 방향키나 WASD, 스와이프로 커서를 옮기고 Enter(ENTER 키), 클릭·탭으로 고르며 Esc나 Backspace(⌫ 키)로 뒤로 간다.

| 플레이 동작 | 키보드 | 휴대폰 |
|---|---|---|
| 방향 입력 | 방향키 또는 W·A·S·D | 화면에서 그 방향으로 스와이프 |
| 마지막 입력 지우기 | Backspace 또는 ⌫ 키 | ⌫ 탭 |
| 실행 | Enter 또는 ENTER 키 | ENTER 탭 |
| 일시정지 | Esc, 또는 입력이 비었을 때 Backspace | 입력을 다 지운 뒤 ⌫ 탭 |
| 입력 전부 비우기 | R | 일시정지의 RESTART |
| 실행 중단 | R 또는 Esc. 입력은 남는다 | 없음 |

레벨은 앞 레벨을 클리어하면 차례로 열린다. 기록(최고 기록, 마지막으로 연 레벨, 실행 속도)은 브라우저에 저장된다. 주소 끝에 `#unlock`을 붙여 열면 저장 기록을 바꾸지 않고 모든 레벨을 연다.

## 파일 구성

| 경로 | 용도 |
|---|---|
| `index.html` | 무대 마크업. 디스크 케이스, 셔터 라벨·HUD, 가운데 창(게임 화면과 메뉴 화면 캔버스 두 장), 입력바 |
| `css/` | 케이스(`case.css`), HUD·상단바(`hud.css`), 입력바(`input-bar.css`), 캔버스·라벨 도장(`screens.css`) |
| `data/stages.js` | 레벨 목차. 단계와 그 단계에 들어가는 레벨 id의 순서이자 해금 순서 |
| `data/levels/<id>.js` | 레벨 하나에 파일 하나 |
| `js/core/` | 규칙(`rules.js`), 레벨 파일 불러오기, 레벨 목록, 저장·해금 |
| `js/gfx/` | 픽셀 그리기 도구와 글꼴, 오브젝트·문양·모니터 그림 |
| `js/play/` | 게임 진행(`session.js`)과 게임 화면 그리기(`board.js`) |
| `js/ui/` | 캔버스 밖 요소(`shell.js`), 메뉴 틀(`menu.js`), 화면 하나에 파일 하나(`screens/`) |
| `js/app.js` | 시작점. 화면 맞춤, 화면 이동, 키보드·마우스·터치 입력 |
| `tools/check-levels.js` | 레벨 검사 스크립트(Node) |

`file://`로 열면 모듈(`type="module"`)과 `fetch`가 막혀서 일반 `<script>`를 쓰고 파일끼리 전역 이름을 공유한다. 레벨 파일은 `index.html`에 적지 않고 `js/app.js`가 목차를 보고 불러온다.

## 레벨 추가

1. `data/levels/`의 레벨 파일 하나를 복사해 `<id>.js`로 저장하고 `defineLevel({ id, name, ko, map })` 내용을 고친다. 파일 이름과 `id`가 같아야 한다. 기호와 이름 규칙은 `data/stages.js` 첫머리 주석에 있다.
2. `data/stages.js`의 알맞은 단계 `levels`에 id를 넣는다. 새 단계는 `{ no, name, ko, levels }` 한 줄을 더한다.
3. 저장소 루트에서 `node tools/check-levels.js`를 실행한다. 목차와 파일이 맞는지, 형식, 이름, 해법, 최단 해법 16회 상한, 제자리 충돌, 4면 외곽 경유를 보고 문제가 있으면 `FAIL`과 이유를 찍은 뒤 종료 코드 1로 끝난다.

스테이지 선택의 탭과 칸, 해금, HUD, 최단 이동 수는 따로 고치지 않아도 따라온다. 최단 해법이 하나뿐인지, 기믹을 건너뛰는 지름길이 없는지는 스크립트가 보지 않으므로 직접 확인한다.
