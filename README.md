# SLIPDISK.EXE 플레이 프로토타입

플로피 디스크 속 컴퓨터가 파일을 먹고, 백신을 먹은 뒤 바이러스까지 먹는 선입력 퍼즐이다. 방향을 미리 입력한 뒤 RUN을 누르면 컴퓨터가 벽에 닿을 때까지 미끄러진다. 1~4단계 12개 레벨이 들어 있다.

- 바로 플레이: https://yangsutae.github.io/SLIPDISK.EXE/
- 로컬 실행: `index.html`을 데스크톱 브라우저에서 연다. `css/`와 `js/`가 같은 폴더에 있어야 하고 설치나 빌드, 인터넷 연결은 필요 없다.

## 조작

| 동작 | 키 |
|---|---|
| 방향 입력 | 방향키 또는 W·A·S·D |
| 마지막 입력 지우기 | Backspace 또는 입력바 클릭 |
| 실행 | Enter 또는 RUN 버튼 |
| 입력 비우고 처음부터 | R 또는 Esc |
| 이전·다음 레벨 | `[`·`]`, 라벨의 ◀·▶, 선택 목록 |

실행 중에 R이나 Esc를 누르면 입력은 남긴 채 실행을 멈추고 레벨 처음 상태로 돌아간다. 결과 화면의 Enter는 클리어했으면 다음 레벨로 가고 아니면 같은 입력으로 다시 시도한다.

## 파일 구성

| 파일 | 용도 |
|---|---|
| `index.html` | 화면 마크업. 디스크 케이스 SVG, 셔터·라벨, 가운데 창, 입력바 |
| `css/case.css` | 무대와 디스크 케이스 모양 |
| `css/game.css` | 레벨 선택, HUD, 보드, 결과 화면, 입력바 |
| `js/levels.js` | 레벨 데이터. 레벨을 추가할 때 고치는 파일 |
| `js/rules.js` | 이동·충돌·백신 규칙, 최단 해법 탐색, 레벨 형식 검사. 브라우저와 Node가 함께 쓴다 |
| `js/render.js` | 캔버스 그리기 |
| `js/game.js` | 레벨 불러오기, 입력과 실행, HUD·결과 화면 |
| `tools/check-levels.js` | 레벨 검사 스크립트(Node) |

`index.html`은 `levels.js`, `rules.js`, `render.js`, `game.js` 순서로 스크립트를 불러온다. `file://`로 열면 모듈(`type="module"`)과 `fetch`가 막히므로 일반 `<script>`를 쓰고, 파일끼리는 `LEVELS`, `step`, `state` 같은 전역 이름을 공유한다.

## 레벨(스테이지) 추가

1. `js/levels.js` 배열에서 단계 순서에 맞는 자리에 `{ id, name, map }` 객체를 넣는다. 기호와 형식은 파일 첫머리 주석에 있다. 레벨 선택 목록, 이전·다음 이동, HUD의 최단 횟수는 따로 고치지 않아도 따라온다.
2. 저장소 루트에서 `node tools/check-levels.js`를 실행한다. 형식 오류, 20회 안에 해법 없음, 최단 해법 16회 초과, 최단 해법 속 제자리 충돌, 4면 외곽 미경유 가운데 하나라도 있으면 그 레벨에 `FAIL`과 이유를 찍고 종료 코드 1로 끝난다.
3. 최단 해법이 하나뿐인지, 의도한 기믹을 건너뛰는 지름길이 없는지, 지워도 해법이 그대로인 벽·파일이 없는지는 스크립트가 보지 않으므로 직접 확인한다.

형식이 틀린 레벨은 브라우저에서도 목록에서 빠지고, 개발자 도구 콘솔에 빠진 이유가 찍힌다.
